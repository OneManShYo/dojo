## WHAT'S NEW

### 🎯 Instant Feedback Everywhere

**Every control tells you what it does!**

The message bar at the bottom of the screen now provides instant feedback:

| Action | Feedback |
|--------|----------|
| Hover a knob | Shows what it does + keyboard shortcut |
| Press a key | Shows the new value or state |
| Error occurs | Shows what went wrong |

Colors mean things:
- **Cyan** = Help (what something does)
- **Orange** = State (what just happened)
- **Magenta** = Error (something went wrong)

---

### 🎹 PERFORM Tab Controls

**44 controls with instant feedback!**

**Keyboard:**
- Press `1-4` → "Track N selected"
- Press `5` → "Master selected"
- Arrow keys → Shows current value
- `,` `.` `<` `>` → Shows mute/solo state
- `Shift+M/T/W` → Shows grid visibility
- `[ ]` → Shows zoom level
- `WASD` → Shows current cell

**Mouse:**
- Hover any knob → See keyboard shortcut
- Hover any button → See what it does
- Move away → Message clears

No more guessing what controls do!

---

### 📁 User-Created Sets

**Organize your containers your way!**

In ORGANIZE tab:
1. Click "+ Set" to create a new set
2. Drag containers into your set
3. Filter by set in ORGANIZE or PERFORM

Use cases:
- "Friday Set" - containers for tonight's gig
- "Bass Heavy" - all your bass-focused visuals
- "Chill Vibes" - mellow shaders for background

---

### 🎵 Auto-Play Library

**Preview audio instantly!**

Toggle auto-play in ORGANIZE toolbar:
- **ON:** Click container → audio plays
- **OFF:** Click container → silent selection

Great for finding the right track quickly!

---

### ⚡ Faster Save

**No more waiting!**

Save workflow now runs in background:
- UI stays responsive
- See progress indicator
- Continue working while it saves

## KEYBOARD QUICK REFERENCE

### Track Controls (1-4 selected)

| Key | Action |
|-----|--------|
| `↑` `↓` | Volume up/down |
| `←` `→` | Shader opacity |
| `,` | Audio mute |
| `.` | Audio solo |
| `<` | Shader mute |
| `>` | Shader solo |

### Master Controls (5 selected)

| Key | Action |
|-----|--------|
| `↑` `↓` | Master volume |
| `←` `→` | Tempo |
| `,` | Master audio mute |
| `<` | Master shader mute |

### Grid & Navigation

| Key | Action |
|-----|--------|
| `W` `A` `S` `D` | Move cell cursor |
| `Enter` | Launch cell |
| `Space` | Play/Pause |
| `Escape` | Stop all / Scene mode |
| `Shift+M` | Toggle master grid |
| `Shift+T` | Toggle track grid |
| `Shift+W` | Toggle waveform |
| `[` `]` | Zoom out/in |

## WORKFLOW TIPS

### Learn Keyboard Shortcuts

1. Hover over any control
2. Read the cyan message
3. Shows keyboard shortcut in parentheses
4. Example: "Audio Volume (↑/↓)"

### Monitor Your Actions

Watch the message bar as you work:
- Orange = confirms your action
- Shows exact values ("Shader: 80%")
- No need to look at controls

### Create Sets for Gigs

1. Create set: "Friday Night"
2. Add containers you'll use
3. In PERFORM, filter to your set
4. Only see what you need
