## WHAT'S NEW

### 🎮 Ergonomic Performance Controls

**No More Shift Key!**

Opacity moved from `Shift+↑↓` to `←→`

**Right Hand (Arrow Cluster):**
- `↑↓`: Volume (vertical)
- `←→`: Opacity (horizontal) ← NEW!
- No modifiers needed!

## KEYBOARD SHORTCUTS

**Updated:**
- `←→`: Opacity (was Shift+↑↓)
- `[` `]`: Zoom (new!)

**Unchanged:**
- `↑↓`: Volume
- `Space`: Play/pause
- `Esc`: Emergency stop
- `WASD`: Navigation
- `1-5`: Track selection
